# IDF 管网空间解析器

面向金陵航煤改造项目的固定 IDF 管网三维审阅系统，生成三维管道实体模型和拓扑图。

## 功能

- 数据源固定为 `金陵航煤改造项目IDF文件`，不提供其他项目导入入口
- 启动后自动载入该项目的全部预解析管线
- 从几何记录提取元件代码、起终点坐标、公称直径、序号和 SKEY
- 基于坐标哈希重建节点与边
- 实体 / 拓扑双视图、管线筛选、元件分类筛选
- 项目资源树、管线搜索、实时 FPS、左右检查面板和全屏审阅界面
- 隐藏、隔离、半透明、聚焦、缩放、自动旋转等模型审阅工具
- 点击三维元件查看源文件行号和工程属性
- 弯头、异径管、法兰、三通/支管座、阀门、仪表和杂项管件的分类实体几何
- 项目总览采用按类别聚合的 LOD 线段，选中单条管线后自动切换精细管件模型
- 按 ISOGEN 2012 R2 SKEY 指南显示准确管件名、元件族、端部形式、PCF 类型和 IDF 记录
- 解析完全在浏览器本地进行，不上传 IDF 内容

## 本地运行

Windows 下可直接双击项目根目录中的：

```text
启动金陵航煤管网审阅系统.bat
```

启动程序会在后台运行本地服务并自动打开系统页面。

也可以手动运行：

不要直接双击 `index.html`，请用静态服务器运行：

```powershell
python -m http.server 8082 --directory idf-web-viewer
```

然后访问 `http://localhost:8082`。

源 IDF 有更新时，重新生成内置项目数据：

```powershell
node idf-web-viewer/build-project-data.js
```

## 解析规则

几何主体记录按以下字段读取：

```text
元件代码 X1 Y1 Z1 X2 Y2 Z2 公称直径 连接序号, ..., ..., SKEY, ...
```

目前对弯头、支管、三通、异径管、仪表、法兰、阀门、过滤器、管帽和活接头等常见 IDF 记录代码做分类映射；未知的正数几何代码仍会以“管件”显示。坐标保持原始精度，渲染时仅做居中和等比归一化。
